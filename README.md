## 🛠️ Bugun O'rganilgan Mavzu: Basic Math in Python

Bugun Python-da matematik amallar va ularning sintaksisini mukammal ko'rib chiqdim:

| Operator | Nomi | Vazifasi | Misol | Natija |
| :---: | :--- | :--- | :--- | :--- |
| `+` | Addition | Qo'shish | `10 + 5` | `15` |
| `-` | Subtraction | Ayirish | `10 - 5` | `5` |
| `*` | Multiplication | Ko'paytirish | `4 * 3` | `12` |
| `/` | True Division | Haqiqiy bo'lish (har doim float) | `10 / 2` | `5.0` |
| `//` | Floor Division | Butun sonli bo'lish (yaxlitlash) | `7 // 2` | `3` |
| `%` | Modulo | Qoldiqni topish | `10 % 3` | `1` |
| `**` | Exponentiation | Darajaga ko'tarish | `5 ** 3` | `125` |
